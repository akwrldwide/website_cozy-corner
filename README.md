# Cozy Corner — Boutique Sanctuaries

A modern, responsive, and accessible website for **Cozy Corner**, offering refined boutique apartments across European capitals for the discerning modern traveler.

![Cozy Corner Logomark](logo.png)

## ✨ Features

- **Hero & Search Experience**: Floating interactive search bar with city selection (Amsterdam, London, Paris), native date pickers, and guest counter modal.
- **Top Picks Showcase**: Handpicked apartment listings with real-time rating badges, night rates, amenity pills, wishlist favoriting, and category filtering.
- **Curated Amenities ("Everything You Need")**: Responsive card grid detailing high-speed fiber Wi-Fi, 24/7 concierge support, 600-thread Egyptian linens, and smart keyless entry.
- **Guest Testimonial Carousel**: Interactive verified guest stories featuring custom quotes, avatars, and verified stay badges.
- **Instant Booking Modal**: Real-time nights and price calculator with itemized breakdown (nightly rate, cleaning fee, taxes) and confirmation dispatch.
- **Dark & Light Mode**: Seamless dark aesthetic powered by Tailwind with an anti-FOUC script and localStorage persistence.
- **Custom Branding**: Bespoke transparent vector logomark integrated across the header, footer, and favicon.

## 📁 Project Structure

```text
├── index.html       # Semantic HTML5 layout with Tailwind CSS
├── styles.css       # Custom animations, surface elevation, and dark mode typography
├── app.js           # Interactive state: search, filtering, modals, carousel, and theme
├── logo.png         # Transparent brand logomark
├── favicon.png      # High-res browser icon
├── favicon.ico      # Root favicon fallback
└── README.md        # Documentation
```

## 🚀 Quick Start

Open `index.html` directly in any modern web browser, or serve it locally:

```bash
# Using Node.js
npx serve .

# Using Python
python -m http.server 8000
```
